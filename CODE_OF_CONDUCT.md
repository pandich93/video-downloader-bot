# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short:

- Be respectful and assume good intent. Critique code and ideas, not people.
- No harassment, insults, discrimination or personal attacks — in issues, pull requests or anywhere
  else you represent the project.
- Do not publish anyone's private information (Telegram IDs, phone numbers, addresses) without consent.
- Help newcomers. Not everyone knows what FFmpeg or MTProto is, and that is fine.

## Reporting

If someone violates these rules, report it privately to the maintainer through
[GitHub's private reporting](https://github.com/pandich93/video-downloader-bot/security/advisories/new)
or a direct message on GitHub. Reports are kept confidential.

The maintainer may edit or delete comments, close issues and block users who break these rules.
